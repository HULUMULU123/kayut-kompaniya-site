# Кают-компания: демо-макет сайта (Хабаровск)

Фронтенд на Vite, GSAP и ванильном JS. Бронирование: заглушка `submitBooking` в `src/api.js`.

```bash
npm install
npm run dev      # http://localhost:5375
npm run build
```

Документы: `DESIGN.md`, `AUDIT.md`, `data/placeholders.md` (всё, что нужно уточнить у владельца).
Скрипты: `scripts/build-ru.mjs` (i18n/ru.json), `scripts/build-poster.mjs` (постер hero), `scripts/resize.py` (размеры фото).
